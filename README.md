\# MatchIQ – Resume \& Job Matching Platform



MatchIQ is a web-based recruitment platform that helps employers find suitable candidates by automatically matching resumes with job requirements. The system extracts information from uploaded resumes and compares candidate skills with job descriptions to generate a matching score.



\## Features



\- User registration and login

\- Candidate and employer roles

\- Resume PDF upload

\- Resume text extraction

\- Job posting and management

\- Skill and keyword matching

\- Cosine similarity-based matching

\- Candidate match score generation

\- Applicant management

\- Database integration



\## Technologies Used



\- Python

\- Flask

\- HTML5

\- CSS3

\- JavaScript

\- SQLite

\- PyPDF

\- Scikit-learn



\## How It Works



1\. Candidate uploads a resume.

2\. MatchIQ extracts text from the PDF.

3\. Employer creates a job posting with required skills.

4\. The system processes the resume and job description.

5\. Relevant skills and keywords are identified.

6\. Cosine similarity is used to compare the resume and job description.

7\. A match score is generated.

8\. Employers can review suitable candidates.
